Supported Actions

  • Navigate: Open a URL in the browser
  • Click / Double-click: Click an element by CSS, XPath, ID, JSPath, ARIA label, and more
  • Type / Clear: Enter or clear text in input fields
  • Select: Choose a dropdown option by text, value, or index
  • Key Press: Send Enter, Tab, Escape, arrows, and other keys
  • Hover: Move the mouse over an element
  • Wait / Wait For Element: Pause execution or wait for an element to appear
  • Execute JavaScript: Run arbitrary JavaScript code
  • Assert Title / Text / Visible / URL: Verify page state
  • Screenshot / Scroll To: Capture screenshots or scroll to elements
