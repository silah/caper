Supported Actions

  • Navigate: Open a URL in the browser
  • Click: Click on an element (by CSS selector, XPath, ID, etc.)
  • Type: Enter text into input fields
  • Wait: Pause execution for a specified duration
  • Execute JavaScript: Run custom JavaScript code
  • Screenshot: Capture a screenshot of the page
  • Assert Title: Verify the page title
  • Assert Text: Verify element text content
  • Scroll To: Scroll to a specific element
